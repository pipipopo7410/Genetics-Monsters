# 小怪獸遺傳實驗室 2.0｜第三輪完整專案

這是**原版風格精修的第三輪**。保留原版小怪獸造型、三對同源染色體、細胞膜和等位基因位置線，並加入七年級循序探究、九年級顯隱性提示、受精動畫及「先手動一胎，再連生五胎」的功能。

## GitHub Pages 部署

1. 先將下載的 ZIP **解壓縮**。**不要直接把 ZIP 上傳到 GitHub，GitHub 不會幫你解壓縮。**
2. 開啟 GitHub 專案 → `Add file` → `Upload files`。
3. 上傳解壓縮後資料夾內的**全部內容**，包含 `index.html`、`style.css`、`app.js`、`README.md` 和 `assets` 資料夾（11 個 `.webp`）。
4. 確保 `index.html` 位於儲存庫根目錄，所有圖片在 `assets/` 資料夾，檔案名稱保留原樣；提交 Commit。
5. 若新建儲存庫，至 `Settings` → `Pages` 設定來源為部署分支（例如 `main`），根目錄 `/ (root)`。

## 設計與操作重點

- 主要為橫向操作，手機直向可切換畫面；整頁沒有上下左右捲動。
- 由爸爸、媽媽的體細胞選出配子染色體，三對同源染色體每對選一條；選入同一對的另一條會彈回，不直接取代。
- 整條染色體與基因座線條一起拖曳；也可以直接點選。
- 精子尾巴朝左且在細胞膜外；兩配子向中間靠近後顯示受精結果。
- 親手完成一次受精後，才解鎖連續生育五胎；小怪獸家族紀錄含子代染色體圖。
- 本版模擬三對染色體承載七項性狀，不模擬染色體互換；同條染色體的基因一起遺傳。
- 若要在電腦直接開啟，打開 `index.html` 即可；圖片都使用相對路徑，檔案需保持原目錄結構。

## 上線前驗收

- [ ] iPad 橫向：三個細胞、兩個配子、下排小怪獸都清楚顯示，沒有滾動。
- [ ] 手指拖曳時是整條染色體移動，同源第二條會彈回。
- [ ] 精卵完成後，「受精作用」按鈕浮現，兩個配子靠攏融合。
- [ ] 受精卵與子代小怪獸外觀正確，且家族紀錄可查看染色體。
- [ ] 先手動生一胎後，連生五胎才解鎖，而且會依序播放每胎動畫。
- [ ] 九年級模式的顯性／隱性資訊在上方標籤呈現。
- [ ] 手機直向仍可操作，且全頁無垂直或水平捲動。
