# 小怪獸遺傳實驗室 2.0 — 第五輪修正版

## GitHub Pages 部署

解壓縮後，將**ZIP 內全部項目**直接上傳到同一個 GitHub Repository 根目錄（或 GitHub Pages 設定的發布目錄）。不要連外層「第五輪」資料夾一起上傳。

```text
index.html          網站入口（內含輕量小怪獸圖片備份，避免圖片路徑錯誤）
style.css           版面與動畫
app.js              遺傳運算、拖曳、受精、紀錄
assets/             11 張可獨立修改的 WebP 素材
README.md           本說明
```

若 GitHub 頁面仍舊顯示舊版本，請刷新瀏覽器或在網址後加上 `?v=5` 重新載入。版本名稱應顯示「第五輪精修」。

## 本次修正

1. **圖片未載入**：`index.html` 內嵌原版 11 張 WebP 的備援資料，不依賴 assets 路徑仍可正確顯示；同時保留獨立圖片，方便日後維護。
2. **精子染色體置中**：將三條染色體的圖形與文字整組移回中央。
3. **配子 → 體細胞拖曳**：可以按住配子中的一條染色體，拖回相同親代的細胞；也可輕點該染色體移除，再重新選擇。不會直接替換已選的另一條同源染色體。
4. **精子比例縮小**：橢圓形精子細胞膜略縮小、尾巴仍在外面且朝左，卵子大小維持不變。

## 保留內容

- 七年級循序揭露／九年級上方顯隱性提示；七年級沒有顯隱性對照表
- 同源染色體選到第二條會彈回
- 精卵受精融合動畫；手動完成 1 胎後可連生 5 胎
- 家族紀錄含子代圖片與受精卵染色體
- 瀏覽器頁面全版鎖定、不得左右或上下捲動

## 驗收建議

- iPad Safari：爸爸媽媽小怪獸都能載入、精子中三條染色體在中央
- 放入某對染色體後，將它拖回原體細胞，再重新選另一條
- 精子明顯小於卵子；動畫仍能完成
- 七年級不出現顯隱性對照表，九年級上方直接顯示顯隱性
- 手動生 1 胎、連生 5 胎以及紀錄簿仍可操作
